# v3.3.0 — Editable charts & tables 📋 Planned

**Theme:** Move charts (and pivot tables) from read-only renders toward Hex's
editable canvas — without building a visualization editor from scratch, by
adopting the `@vinci/designer` that's **already a dependency**.

## Why

`components/thread/ThreadChart.tsx` is explicitly read-only ("no editor, no source
picker"): the DSL the visualization sub-agent emits is fixed. Hex lets a user
switch chart type, change axes/series/aggregation, and **edit a chart in natural
language** ("make it a bar chart", "group by month"). There's no chart export
either. `@vinci/designer` (the editable counterpart of `@vinci/viewer`) is in
`package.json` but unused — it edits **both charts and tables**, so it unifies
this with the v3.1 grid's rich surface.

## What ships

- **"Edit in words":** a prompt on a chart that re-delegates to the
  `visualizationAgent` with the current chart as upstream context, swapping in the
  returned DSL (`tools/delegate-visualization.ts` + `agents/visualization.ts`).
  This approximates Hex's NL chart edits with no new editor UI.
- **Direct edit via `@vinci/designer`:** swap the read-only viewer for the
  designer in an "edit" mode — chart-type switch, axis/series/aggregation, and
  table pivot/column config, all on the existing `compileSurface` trio (the
  designer decompiles edits back to DSL).
- **Chart export:** PNG/SVG download from the chart card.
- **Multiple upstream sources:** clarify behavior when a viz references more than
  one result (today single-source is assumed).

## Out of scope / deferred

- Persisting an edited chart/table as a durable artifact (→ v3.4 pinning).
- A full free-form dashboard canvas (icebox — `Canvas.dc.html`).

## Done when

- [ ] A user can restyle an existing chart with a natural-language prompt and see
      it update in place.
- [ ] The vinci designer edits charts and pivot tables on the existing compile
      pipeline; edits round-trip to DSL.
- [ ] Charts export to PNG/SVG.
- [ ] The heavy designer is lazy-loaded (no regression to inline render cost).
- [ ] `typecheck` + `lint` + `test` (both apps) + web `build` + agent `smoke` green.
