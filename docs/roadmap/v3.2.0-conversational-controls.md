# v3.2.0 — Conversational controls 📋 Planned

**Theme:** Make the conversation reworkable — edit/resend, regenerate,
suggested follow-ups, and per-step retry — instead of a one-shot stream that
locks once it finishes.

## Why

Once a stream ends, the turn is frozen. The composer can only send a new
message (`Composer.tsx`); past messages aren't editable; a failed run can only be
stopped wholesale (the `useThreads` stop path aborts the entire stream — there's
no resume from the failed tool step). And there are **no suggested follow-ups** —
Hex Threads' signature "what next" affordance — outside the empty-state examples.
This is where the thread feels like a transcript rather than a workspace.

## What ships

- **Edit & resend** a user message: truncate the history after that message
  (`lib/threads.ts` reconstruction already keys off stored parts) and re-run.
- **Regenerate** an assistant answer (re-run the same user turn).
- **Suggested follow-ups:** 2–3 next-step questions after an answer, rendered as
  clickable chips that send on click. Implementation path TBD in design — either
  the analyst emits structured follow-ups at the end of its turn, or a cheap
  separate generation call derives them from the answer + result columns.
- **Per-step retry:** when a tool step errors, retry from that step rather than
  re-running the whole turn (extends the `tool-error` handling in `useThreads`).

## Out of scope / deferred

- Branching / forking a conversation to explore alternatives (icebox).
- Multi-turn "undo" beyond truncate-and-rerun.
- Streaming-time editing (edits apply after the current stream settles).

## Done when

- [ ] Editing + resending a user message correctly truncates and re-runs; history
      rebuild stays correct on reload.
- [ ] Regenerate re-runs the turn; follow-up chips appear after answers and send
      on click.
- [ ] A failed tool step can be retried without repeating already-succeeded steps.
- [ ] No regression to the `analyst` stream contract or persisted-history rebuild.
- [ ] `typecheck` + `lint` + `test` (both apps) + web `build` + agent `smoke` green.
