# v1.1.0 — External context ✅ Shipped

**Theme:** Let the agent reach beyond the warehouse — the **web** and **uploaded
files** — so Thread mode can answer questions the warehouse alone can't.

## Goal

Let **Thread mode reach beyond the warehouse** — web search/extract and reading
uploaded files — treated as untrusted reference material.

## Why

Hex's analyst can search/extract the web and read uploaded files (CSV, images).
Dex is warehouse-only, so it can't verify an external fact or look at a one-off
upload. This is a **Thread-mode** agent capability (no notebook required), treated
as untrusted reference material.

## Scope

- **`search_web` / `extract_web`** (Hex `SearchWeb` / `ExtractWeb`) — ranked web
  search + page extraction; results are clearly marked **untrusted** and never
  executed as instructions. (No kernel needed — ships here.)
- **`get_file_contents`** (Hex `GetFileContents`) — read user-uploaded files:
  text/images as context, and small CSVs parsed for preview/quick stats.
- **Provenance** — external claims cite their source.

## Out of scope

- **Autonomous browsing / crawling at scale.**
- **Heavy CSV dataframe analysis** — full dataframe work composes with the kernel
  ([v2.3](./v2.3.0-python-kernel.md)); this milestone delivers reading + web, not
  a compute runtime.

## Technical notes

- Web via a search/extract provider; uploads stored and read by id. Web + file
  reading need no kernel, so they ship in the Thread-mode track; once the kernel
  lands (v2.3) a CSV can be promoted to a queryable dataframe.

## Acceptance criteria

- [x] The agent answers a question that needs a **web lookup**, with a
      **citation**; web content is marked untrusted and never executed as
      instructions. (Provider is Tavily via `TAVILY_API_KEY`; unconfigured reports
      cleanly.)
- [x] The agent **reads an uploaded file** (text / small CSV) and uses it in an
      answer (composer "+" → upload → `get_file_contents`).
- [x] **Verification green:** both apps `typecheck`; agent tests/smoke cover the
      new tools with a mocked web provider (no live network in CI).
