# v0.9.0 — Agent knowledge & memory ✅ Shipped

**Theme:** Give the agent durable knowledge — **org guides** it consults for
business definitions, and **memory** of user preferences across threads.

## Goal

Give the agent **durable knowledge it consults** (org guides) and **memory of
user preferences across threads**, so it stops re-deriving definitions and
forgetting context.

## Why

Hex's analyst reads org **guides** (metric formulas, terminology, approved
query/filter patterns) and **saves** stable user preferences. Dex has only
per-thread conversation memory and no guides, so it re-derives definitions every
time and forgets cross-thread context. This milestone gives the agent a place to
look things up and a place to remember.

## Scope

- **Guides store + `read_guide` tool** (Hex `ReadGuide`) — markdown guides
  (definitions, terminology, approved patterns) persisted in `dex.db` with a
  small authoring UI; the agent's instructions tell it to consult relevant guides
  early and treat their definitions as the standard.
- **`save_memory` tool** (Hex `SaveMemory`) — persist a confirmed user
  preference/convention across threads (resource-scoped) and inject it into
  context on later turns.
- **`suggest_review`** (Hex `SuggestReview`) — when interpretation is ambiguous
  or confidence is low, surface a "request a data-team review" affordance.
- **Progressive answering** — return a quick initial answer, then keep deepening
  the analysis (a behavior, per Hex's "cursory reply then continue").

## Out of scope

- **RAG over external corpora / doc ingestion** — that's external context (later).
- **Automatic memory extraction** — saves are explicit/confirmed only, never
  silent.

## Technical notes

- Guides persist in `dex.db` (`db/guides.ts`, mirroring `semantic/store.ts`) with
  root REST routes; `read_guide` is a thin tool over them.
- `save_memory` uses Mastra working/semantic memory or a `dex.db` preference table
  keyed by `RESOURCE_ID`; recalled preferences are folded into the agent context.

## Acceptance criteria

- [x] A guide can be authored + stored; **`read_guide`** returns it and the agent
      **applies its definition** in an answer (e.g. uses the guide's metric
      formula instead of re-deriving one).
- [x] **`save_memory`** persists a confirmed preference that is **honored in a
      later, separate thread** (folded into the agent's system prompt every turn).
- [x] An ambiguous question triggers **`suggest_review`** alongside a complete
      answer (not instead of one).
- [x] Progressive answering: a deep question returns a quick initial answer, then
      a continued, deeper result.
- [x] **Verification green:** `npm run smoke` covers guide + memory persistence;
      both apps `typecheck`.
