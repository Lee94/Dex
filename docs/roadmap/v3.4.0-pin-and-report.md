# v3.4.0 — Pinning & reports 📋 Planned

**Theme:** Let analysis leave the conversation — pin results into a report,
export it, and share it. Fills the biggest hole the v3.0 notebook removal left:
there is currently **no way to turn a thread into a durable, shareable artifact**.

## Why

v3.0 made results "ephemeral to the conversation" — good for simplicity, but it
dropped Hex's core payoff: sinking analysis into a sharable report/app. Today the
only durable outputs are CSV/clipboard copy and the thread transcript itself.
There's no pin/favorite, no report/export, and the header **Share** button is
inert (`ThreadView.tsx:123`). This version reintroduces a **lightweight**
persistence layer for it — not the retired notebook.

## What ships

- **Pin a result/chart** into a thread- or project-level **report/canvas** (a
  simple ordered, reorderable collection of pinned cards).
- **Export:** report → Markdown first, then PDF.
- **Share:** wire the header **Share** button to a read-only link (a single-user
  read-only snapshot is enough at this stage).
- **Persistence (new, lightweight):** `dex_pins` / `dex_reports` tables via
  `db/store.ts`'s lazy `ensureSchema` pattern, plus a root REST module
  (`server/report-routes.ts`, modeled on `project-routes.ts`); web `lib/reports.ts`
  + `components/report/*`. Secrets never enter the DB (per existing convention).

## Out of scope / deferred

- A free-form dashboard **Canvas** (`Canvas.dc.html`) — pins are an ordered list
  here, not a board (icebox).
- Scheduled/automated report delivery (overlaps v1.3 scheduling; not in scope).
- Multi-user permissions on shared links (→ v3.5).

## Done when

- [ ] A result or chart can be pinned, and pins render in a report view that can
      be reordered.
- [ ] A report exports to Markdown (PDF follow-on acceptable).
- [ ] The Share button opens a working read-only link.
- [ ] New tables persist in `dex.db` via lazy `ensureSchema`; no credentials in
      any DB.
- [ ] `typecheck` + `lint` + `test` (both apps) + web `build` + agent `smoke` green.
